# Student Performance Analysis Dashboard

## 📌 Overview
This project analyzes student performance using Python. It calculates total marks, percentages, grades, and ranks, and visualizes the data using charts created with Matplotlib.

## 🚀 Features
- Calculate total marks
- Calculate percentage
- Assign grades based on percentage
- Rank students based on performance
- Display summary statistics
- Visualize data using charts

## 🛠️ Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Jupyter Notebook

## 📊 Visualizations
- Bar Chart
- Pie Chart
- Histogram

## 📁 Dataset
The project uses a sample dataset containing:
- Student Names
- Maths Marks
- Science Marks
- English Marks

## 📈 Calculations Performed
- Total Marks
- Percentage
- Grade
- Rank

## ▶️ How to Run
1. Clone this repository.
2. Install the required libraries:
   ```bash
   pip install numpy pandas matplotlib
   ```
3. Open the notebook:
   ```
   Student Performance Analytical Dashboard.ipynb
   ```
4. Run all cells.
